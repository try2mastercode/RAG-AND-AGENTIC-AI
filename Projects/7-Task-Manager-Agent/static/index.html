How this agent actually works

Every stage below is a real step in the graph, not a simplification:

1

agent node

Your message (plus the saved conversation) goes to the LLM, which either replies directly or asks to call one or more tools.

→
2

tools node

A prebuilt ToolNode runs whichever of add_task, list_tasks, update_task, complete_task, delete_task the model asked for.

→
3

loop

Tool results go back to the agent node, which can call more tools or stop — tools_condition decides which, until the model gives a plain answer.

→
4

checkpoint

A SqliteSaver saves the graph's state after every step, keyed by thread_id — that's how it remembers you after a page refresh or restart.

→
5

interrupt

delete_task calls interrupt() before touching the database, which pauses the whole graph mid-run and hands control back to you.

→
6

resume

Your yes/no answer is sent back as Command(resume=...), and the graph continues delete_task from exactly where it paused.
