🎛️ Multimodal Studio

A project built to demonstrate image, speech, and text-to-speech pipelines — each panel hits a different Groq model, and the last panel chains two of them together.

View raw API docs (Swagger UI) →

One model per modality, one client for all of them

"Multimodal" doesn't mean one model does everything — it means routing each kind of input to the model built for it, then optionally chaining the outputs:

1

Image → text

A vision-capable chat model (qwen3.8-27b) reads a base64-encoded image straight inside the chat message.

→
2

Audio → text

Groq's hosted whisper-large-v3 transcribes an uploaded or recorded audio clip.

→
3

Text → audio

orpheus-v1-english turns plain text back into a spoken .wav file, streamed back as raw bytes.

→
4

Fusion: chaining models

Panel 4 feeds the output of the vision model straight into the TTS model — image → caption → speech, no manual step in between.
