⚔️ Retriever Showdown

A mini project comparing five advanced retrieval strategies on the exact same question and document collection — run live against Groq and a real vector store, with a plain HTML/CSS/JS frontend wired straight to the FastAPI backend.

View raw API docs (Swagger UI) →

The document collection being searched

All five strategies below search this same fixed set of six sentences — that's what makes the comparison fair.

    How the five strategies differ

    Baseline

    Plain dense vector similarity search. Embeds the question, returns the closest matches. The default, nothing fancy.

    MMR

    Max Marginal Relevance — still dense, but penalizes results that are too similar to ones already picked, trading a little relevance for topic diversity.

    Multi-query

    The LLM rewrites your question 3 different ways, each is searched separately, and the results are merged and de-duplicated — catches matches a single phrasing would miss.

    BM25

    Classic keyword/term-frequency ranking. No embeddings at all — purely how often and how rarely your exact words appear in each document.

    Reciprocal Rank Fusion

    Runs the dense baseline and BM25 over the whole corpus, then fuses their two rankings into one score: 1/(60+rank) per retriever, summed.
