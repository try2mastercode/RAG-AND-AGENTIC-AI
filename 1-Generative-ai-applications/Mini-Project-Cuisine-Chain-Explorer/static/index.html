How a generative-AI API call actually works

Every panel below sends a real HTTP request. Here's the round trip, every time:

1

Browser builds a request

JS collects your input, wraps it as JSON, and fetch()s a backend route like POST /api/sequential.

→
2

FastAPI parses & validates

A Pydantic model checks the JSON shape, then the route hands the data to a LangChain "chain" function.

→
3

Prompt template → Groq

Your data fills a PromptTemplate, producing the actual text prompt sent over HTTPS to Groq's LLM API.

→
4

Response flows back

Groq streams tokens back to the server, an output parser turns them into plain text, FastAPI wraps it as JSON, and JS renders it here.

1. Sequential chain

PromptTemplate | llm | StrOutputParser, three times in a row — each stage's output becomes the next stage's input: location → dish → recipe → cook time.
